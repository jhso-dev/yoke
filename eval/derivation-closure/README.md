# Should `downstreamOf` walk the transitive closure? Measured: no.

`yoke deprecate` reports the records that declared they rest on what was retired — **one
`derived_from` hop**. The obvious upgrade is the transitive closure (dependents of dependents), and
ROADMAP carried it as a ceiling to lift "if a real corpus turns up chains deep enough that one hop
misleads". This measurement is that check, run before building it (2026-08-07).

## Method

Three corpora were generated by three independent LLM simulations of real teams (payments backend,
data platform, mobile release & experimentation), each ~5 months of knowledge accretion: 75–83
records, `derived_from` edges as the simulated authors would actually cite (sparse — 30–42% of
records carry a basis), chains up to depth 4. The generators were **blind to the hypothesis** — they
were asked to simulate honestly, not to produce interesting graphs.

Each corpus carries 5 deprecation events with a **semantic ground truth**: for every event, the
records a steward with full knowledge of the corpus should re-examine, labeled
`invalidated` (actually wrong now) or `survives` (worth a look, stands on other grounds) — judged
from the record texts, not by walking the graph. The same author wrote both the edges and the ground
truth, which if anything favors graph mechanisms.

`harness.mjs` loads each corpus through the real commit gate, runs the real `yoke deprecate --json`
for the one-hop report, simulates the iterative workflow (retire the reported-and-invalidated,
re-report, repeat), and computes the closure. Reproduce with:

```
npm run build:cli
node harness.mjs corpus-a.json   # likewise -b, -c
```

## Results (15 events, 23 invalidated / 69 re-examine ground truth)

| mechanism | recall on invalidated | recall on all re-examine | noise |
|---|---|---|---|
| one hop (shipped) | 0.48 | 0.26 | 0 |
| iterative (one hop + retire + repeat) | 0.48 | 0.32 | 0 |
| **transitive closure** | **0.48** | 0.35 | 3 |

Ground truth by graph distance from the deprecated record:

| verdict | direct (1 hop) | transitive (≥2) | no path at all |
|---|---|---|---|
| invalidated (23) | 11 | **0** | 12 |
| survives (47) | 8 | 6 | 33 |

## Findings

1. **The closure's target population is empty.** Across 15 events in three independent corpora, not
   one truly-invalidated record sat at graph distance ≥ 2. Chains existed (depth 3–4); invalidated
   records at the end of them did not. The closure would have added 6 records that survive anyway,
   plus the only noise in the whole experiment.
2. **The binding constraint is citation coverage, not walk depth.** 12 of 23 invalidated records
   (52%) had **no `derived_from` path at all** — the dependence was real but never declared as an
   edge, typically a fact that *measured* the deprecated thing's world, or a sibling sharing an
   uncited premise. No walk of any depth reaches these.
3. So one hop stays, and the ceiling comment on `downstreamOf` now cites this measurement instead of
   waiting for chain depth: depth is not what decides it.

## Caveats

Synthetic corpora — three LLM-simulated teams, not production data; 23 invalidated ground-truth
records is small. The result is consistent across all three domains, and the setup was biased in the
closure's favor (edge author = ground-truth author), which strengthens a null result. Re-run against
a real corpus when one has accumulated enough `derived_from` history to label.
